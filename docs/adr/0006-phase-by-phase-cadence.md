# 0006: Stop after each merged phase and ask the owner

- **Status:** Accepted
- **Date:** 2026-07-16

## Context

The project is owned by a single decision-maker who approves design. Building several phases without a checkpoint risked large rework.

## Decision

Phase-by-phase cadence: stop after each merged phase and ask the owner before continuing.

## Consequences

Smaller PRs, explicit checkpoints, and a clear place for the owner to redirect.
