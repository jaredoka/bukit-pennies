# 0010: Dashboard drops Daily spend, Month by month, and Top merchants

- **Status:** Accepted
- **Date:** 2026-07-30

## Context

Insights covered month-by-month and top-merchant better than dashboard cards; day-level spending was a weak signal.

## Decision

Dashboard drops Daily spend, Month by month, and Top merchants. Day-level spending now exists nowhere; if it returns it goes on Insights.

## Consequences

A leaner dashboard; Insights is the home of period and merchant breakdowns.
